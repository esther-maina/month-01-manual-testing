# Month 01 — Manual Testing Mastery

## What this is

Week-by-week manual QA work as part of a structured
6-month QA Automation Engineering roadmap.

## Goal

Build a professional manual testing foundation — structured
test cases, defect reporting, Jira workflows, and test
documentation — before moving into automation.

## Structure

- `week-01-fundamentals/` — QA concepts, SDLC, HTTP basics
- `week-02-jira/` — Defect lifecycle, Jira board, test summary
- `week-03-test-design/` — Test case design techniques
- `week-04-documentation/` — Git workflow, test plans, reports

## Stack

Manual Testing · Jira · Markdown · Git
